# Training Studio logo

Generated with the built-in image-generation tool. The source PNG has transparency.
The smaller PNG and Windows ICO are packaging versions of the same artwork.

Prompt:

> A minimal Windows 11 app logo for Training Studio, a local coding model training app. Icon only, no text or letters. A compact continuous loop made from two simple rounded angle brackets, subtly forming an upward step, representing code getting better through repeated learning. Strong simple silhouette, thick consistent geometry, generous negative space, readable at 24px. Fluent design inspired restrained cobalt blue and teal with a very subtle smooth tonal gradient, flat vector-like crisp edges, no fine detail, no sparkle, no brain, no robot, no circuit traces, no charts, no shadows, no mockup. Center the mark with 12% padding on all sides. Transparent background.

The Database, Scales and Brain Circuit vector geometries in App.xaml are from Microsoft Fluent System Icons, commit `a347af95478f989038cccbf085978865264c048a`, under the MIT license. Original paths are unchanged; the theme controls their fill. See `desktop/licenses/fluent-system-icons.txt`.
