# Training Studio 0.1.3

Training Studio has a simpler interface and a continuous loop for local model training.
This release replaces the six-hour limit for new Studio sessions.
Existing sessions keep their saved results and controls.

## Interface

- A new logo identifies the app and its Windows shortcuts.
- The Mica background and translucent panels use the Windows transparency settings.
- The appearance defaults to the Windows theme. Light and Dark remain available.
- One main button changes between Start and Stop. A separate Pause button releases the GPU for gaming.
- Icons and text show the current state, including Running, Paused, Stopped, and Needs attention.
- Home, Activity, Results, and Settings separate daily controls from setup details.
- Background updates no longer disable the toolbar or cause its controls to blink.

## Training loop

- New sessions collect code, train a candidate, compare results, and repeat until Pause or Stop.
- The recipe uses Qwen3.5-4B with Python, Go, TypeScript, Rust, and Dart examples.
- The loop keeps generated programs only after they pass code tests in isolated containers.
- Earlier passing examples remain in the training data to reduce loss of previous skills.
- The base weights stay frozen. Small LoRA adapters receive at most ten optimizer steps per cycle.
- A candidate must gain a validation pass without losing a previous pass before the full comparison.
- The full comparison covers 790 tasks. It also runs every fifth cycle that has a training candidate.
- A candidate replaces the retained model only after the required comparisons pass without lost tasks.
- A rejected candidate does not end the loop. The loop keeps its report and collects new examples.
- Pause preserves progress. Start resumes it. Stop ends the session and preserves its results.
- Login recovery respects saved Pause and Stop commands.

## Install or update

1. Download `TrainingStudio-win-x64.zip` from this release.
2. Extract all files into one folder.
3. Run `install.ps1` with PowerShell.
4. Open Training Studio from the Desktop or Start menu.

The package includes .NET and its license notices. Windows can show an unknown-publisher prompt because the executable has no code signature.
The installer keeps an active worker on its current version. Shortcuts and future worker starts use the new version.

If an older dashboard remains open, close it before you open the new shortcut.
Keep the older app folder until its worker exits.
If an experiment remains active, keep its Python source files unchanged.
Changed source files can prevent that experiment from resuming.

## Requirements and limits

The app requires a prepared WSL CUDA backend, model cache, dataset cache, and isolated code runtime.
It does not install these dependencies. The current recipe targets a 16 GB NVIDIA GPU.

The new loop does not yet establish better coding quality. Public benchmark scores are development results because the loop reuses these tests.
Model files, private data, checkpoints, and local reports are not part of this release.
